# 爱豆收集梦想生活 · Idol Tomodachi Life

像素城市里的韩娱生活模拟游戏：角色按日程活动，玩家通过见面、照顾小心愿、私信和应援参与她们的日常。对话由 DeepSeek 生成；时间、地点、存档和关系事件由游戏管理。

## 运行

需要 Node.js 20.11 或更高版本。

```sh
npm install
npm run dev
```

打开终端给出的地址，默认端口为 3000。开发服务器已经内置 `/api/chat`，无需另外启动 API 服务。

AI 配置任选一种：

- 复制 `.env.example` 为 `.env.local`，设置服务端 `DEEPSEEK_API_KEY`。修改后重启开发服务器。
- 在建号界面或右下角「AI 设置」中填写自己的 Key。Key 仅保留在当前页面内存，刷新后重新填写；不会写入自动存档或手动存档。API 用量由服务商计费。

不要使用 `VITE_` 前缀存储密钥。旧存档中的 Key 会在读取时移除。

## 主要交互

- **城市地图**：右上角「地图」打开像素城市插画。插画上只写地名（后面的数字是此刻在那里的人数，金色下划线是你的位置），不加底框和图标；选中后在右侧看在场人物、进入条件及所属公司／团体，再点击前往。手机可横向滑动地图，地点操作区保持独立。
- **对话演出**：说话的人头顶浮出台词气泡，页面下方是固定的剧情框（旁白、名牌、进度和选项都在这里）。矮屏幕下舞台会压扁、选项区可滚动，剧情框始终完整可见。
- **会话恢复**：暂别会保留本时段、同一地点与同一组角色的对话和阅读位置。回来可继续；没有强制 12 轮退出。切换地点或时段会开始新的会话。
- **照顾小心愿**：先参与至少一次回应，再用「这件事已经办好」确认完成。完成状态在本时段保留，地图不再反复展示同一需求，聊天仍可继续。完成操作不会凭空发放数值奖励。
- **手机私信**：问候、鼓励、提议喝咖啡三种明确动作，回复根据动作、忙闲和熟悉程度生成。每天三条，不因普通问候自动增加曝光；深入自由对话在地图见面后进行。
- **世界关系**：同场角色可能发生有具体原因的事件，同一对角色每天最多结算一次。仅勾选撮合不会额外增加后台好感。
- **回忆**：集中阅读已经发生的剧情；继续互动请回到世界。
- **等待与取消**：生成和重试有明确提示，可取消请求并重试原行动。读档、重开会使旧请求失效，避免覆盖新进度。

## 验证

```sh
npm run lint
npm test
npm run build
npm run test:e2e
```

浏览器测试使用模拟 AI 回复，不消耗 API 配额。Windows 若已安装 Edge 会自动使用；其他环境首次运行需 `npx playwright install chromium`，或用 `PLAYWRIGHT_CHROMIUM_PATH=/path/to/chrome npm run test:e2e` 指向机器上已有的 Chromium。

## 部署

- **Vercel**：使用 Vite 构建，服务端环境变量设置 `DEEPSEEK_API_KEY`，`api/chat.ts` 提供代理。
- **自托管**：`npm run build` 后设置环境变量并运行 `npm start`；默认端口 8080。需要一并部署 `dist/`、`server.mjs` 和 `server/`。
- **Docker**：仓库 Dockerfile 包含静态资源和共享 API 实现。

API 校验消息结构和长度，并限制单次输出上限。使用网站共享 Key 的请求有每实例的每客户端 20 次／小时、总计 200 次／小时基础限制；玩家自填 Key 的请求不使用共享额度。多实例生产部署若需要全站统一配额，应接入共享存储和身份认证；内存限制不跨实例持久化。

## 代码位置

- `src/App.tsx`：游戏协调与状态更新。
- `src/GamePanels.tsx`、`src/story.ts`：建号／手机／回忆界面，以及剧情解析。
- `src/SceneView.tsx`：会话与阅读界面。
- `src/CityMap.tsx`：可点击的城市地图。
- `src/gameState.ts`：状态校验、会话标识和存档迁移。
- `src/chatClient.ts`：请求取消、超时、重试和内存 Key。
- `src/socialSimulation.ts`：轻量私信与关系事件。
- `server/chat.mjs`：开发、Vercel 和自托管共用的 API 代理。
- `public/maps/idol-city.png`：本次通过内置 imagegen 生成的地图插画，文字与交互由 HTML 叠加。

手机请横屏游玩：竖屏会显示提示页，横过来即可继续，场景是宽屏构图。

本作为韩娱向平行世界虚构游戏，角色剧情均为虚构创作。
