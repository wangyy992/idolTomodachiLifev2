# 地图插画生成记录

使用工具：内置 imagegen（非 CLI）。

项目资产：`public/maps/idol-city.png`

插画不含地点文字，地点名称、人数、锁定状态和旅行按钮由 `src/CityMap.tsx` 绘制。这样可以保持移动端文字清晰、键盘可操作，并兼容动态日程。
