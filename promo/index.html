游戏简介

一座自己过日子的偶像小岛

你不是在推剧情，而是在照看一个持续运转的世界。

这是一款《Tomodachi Life》式的俯视沙盒养成游戏：几组偶像各有自己的作息与档期，在一座小岛上照常练习、打歌、巡演、发呆。你以圈内工作人员的身份进入，走近头顶冒气泡的她、满足一个小小的需求，就展开一段由 AI 现场生成的对话。

好感攒够，她头顶会亮起金光 —— 那是一场专门为你写的重头戏。

它的内核是一套「确定性模拟 + 生成式 AI」的混合叙事：游戏用代码稳稳掌管时间、日程、需求与关系数值，保证世界连续可信；大模型只负责演好"此刻这一场"，既开放自由，又不会失控。

技术架构

怎么把 LLM 稳稳接进一个开放世界

混合叙事架构
用 FNV-1a 确定性哈希驱动日程 / 需求 / 打歌成绩 / 关系数值，世界连续可控；LLM 只生成当下单场对话，兼顾自由度与稳定，并大幅降低 token 消耗。
结构化输出协议
定义状态快照 / 关系变化 / 里程碑等标签，前端解析后落库，把自由文本变成可持久化、可结算的游戏状态。
稳定性设计
DeepSeek 经 Serverless 代理隐藏密钥；针对慢生成与网络抖动做指数退避重试 + 确定性兜底，避免"AI 返回了界面却报错"。
体验完整度
角色创建与捏脸、俯视世界与 VN 对话双视图、仿真手机、结局年鉴、新手引导、简繁双语与移动端适配。
